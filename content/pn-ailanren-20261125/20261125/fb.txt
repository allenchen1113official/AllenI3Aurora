Claude Code 接了一堆 MCP，context 還是很快就滿？🤔
叫它從 200 個 issue 挑出 5 個跟登入有關的，另外 195 個的內容也全留在對話裡，之後每一輪都要重讀。

AI懶人報 EP492 整理了 Claude Code 新的實驗功能 Code Mode，重點有這幾個：

1️⃣ 做法不同：Claude 改寫一段 JavaScript，把工具當函式呼叫，在程式裡篩完，只把那 5 個帶回來。
2️⃣ 省在哪：社群實測新對話開場少約 2 萬 token，大任務讀進的 token 可少七成（官方沒有公布節省數字）。
3️⃣ 別期待太多：重複讀的對話有快取折扣，多數實測帳單只省一到兩成。
4️⃣ 不是每次都快：逐一檢查大量連結反而慢了四倍，簡單問題也常慢幾秒。
5️⃣ 先知道限制：目前只能在終端機用，版本要 2.1.323 以上；Auto Mode 只審整段程式，git push、刪檔這類指令記得寫成 ask／deny 規則。

結論：工具呼叫多、常撞用量上限的終端機重度用戶可以試；主要用 Desktop 或 VS Code 的人，先等它離開實驗階段。
