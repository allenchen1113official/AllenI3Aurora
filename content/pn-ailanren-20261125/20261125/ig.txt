Claude Code 的 Code Mode 值不值得開？👇

📌 它在做什麼
Claude 先寫一段程式，在裡面篩完資料，只把答案帶回來

✔️ 開場 context 少約 2 萬 token（社群實測）
✔️ 大任務讀進的 token 少七成
✔️ 每個改動都走 edit，看得到 diff

⚠️ 但要知道
✔️ 有快取折扣，帳單多半只省 1～2 成
✔️ 一個連結一個指令的工作，慢了 4 倍
✔️ 只能在終端機用

📌 5 個馬上能用的做法
1. 任務一次講完整，說清楚要回報什麼
2. 跨多個 MCP 工具，叫它串在同一段程式
3. 大檔案先讀進變數，再逐題追問
4. Ctrl+O 展開看它寫的程式
5. 危險指令寫成 ask／deny 規則
