寫程式 10 分鐘，送上線卻要一下午？😮

📌 Claude Code /ship 的四步
✔️ 自動 commit、開 PR
✔️ 用 code review 自己審
✔️ 最長 7 天盯著 PR 修到測試通過
✔️ 通過後通知你，合併由你按

📌 可以放心交出去的
✔️ 測試紅燈
✔️ 與主線衝突
✔️ 同事要求的小修改

📌 要自己看的三個風險
✔️ 沒存的變更連新檔案全部 commit
✔️ 用你的 GitHub 帳號動作
✔️ 開了自動合併，可能沒人看過就上線

📌 三條守門規則
✔️ GitHub 設至少一人批准
✔️ 新 commit 讓舊批准失效
✔️ 團隊版設手動觸發與花費上限

記住這句：AI 補件，人簽名。

先收藏，之後設定時對照！分享給每天在等 CI 的朋友 🙌

💡 一句話總結：AI 能把送件補件跑完，但最後簽名合併的仍應是人。
