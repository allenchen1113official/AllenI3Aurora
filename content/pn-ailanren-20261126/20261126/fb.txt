寫功能 10 分鐘，開 PR、等測試、修紅燈、回留言卻花掉一整個下午，你是不是也這樣？

Claude Code 新增的 /ship 就是要接手這段。這集 AI懶人報 把 Claude Code /ship 的重點整理如下：

1️⃣ 它做四件事：把變更 commit 並開 PR、用 code review 自己審、最長 7 天盯著 PR 修到測試通過，最後通知你可以合併。

2️⃣ 開啟條件：Claude Code 要更新到最新版、gh 要先登入、只能在終端機跑。Bypass Permissions 模式與原生 Windows 不會啟動看守。

3️⃣ 可以放心交給它的：測試紅燈、與主線衝突、同事要求改個名字或錯字，這些不難但很耗時間。

4️⃣ 要自己看的三個風險：它會把你還沒存的變更連新檔案全部 commit，檢查金鑰只看檔名；它用你的 GitHub 帳號動作；專案若開了自動合併，修正推上去後可能沒人看過就合併。

5️⃣ 守門靠規則：GitHub 設至少一人批准，且新 commit 要讓舊批准失效；團隊版先設手動觸發並加花費上限。

一句話：AI 可以幫你把送件補件跑完，最後簽名的還是要人。
