動作感測器抓不到坐著看電視的人？用 ESP32＋ESPresense 做逐房間偵測的 5 個重點

📌 重點摘要
• ESPresense 是跑在 ESP32 上的開源藍牙追蹤韌體：每個房間放一台，依哪台收到手錶／手環訊號最強，判斷你在哪個房間。
• 它更新不夠快，不適合「進門前先開燈」；強項是判斷房間有沒有人，搭配動作感測器在人離開後自動關燈。
• 安裝不用編譯：瀏覽器用 ESP Web Tools 燒錄，連 ESPresense 熱點進 192.168.4.1 填 Wi-Fi、MQTT 與房間名稱。
• 進 Home Assistant 前要有 MQTT broker；開自動探索就會出現節點實體，個別裝置則要從日誌找 ID、用 MQTT room 平台建感測器。
• 作者偏好用 Fitbit 等穿戴裝置當信標，手機有限制；實測 iPhone 原生也能用，追蹤 Apple 裝置記得開「查詢裝置特性」。

📝 康乃爾筆記
🔹 原理：多台 ESP32 收藍牙信標，訊號最強的節點＝你所在的房間。
🔹 適用場景：判斷房間是否有人、離開後關燈；不適合搶快開燈，那交給動作感測器。
🔹 準備清單：每房一台 ESP32（大房間加量）、穿戴式藍牙信標、Home Assistant＋MQTT broker。
🔹 設定重點：關狀態 LED、開查詢裝置特性、最大回報距離≈房間尺寸；追蹤值要複製 ID 欄而非 MAC 欄。
🔹 下一步：把房間狀態當自動化條件使用；作者希望 ESPresense 併入 ESPHome、整合進牆面開關。

💡 一句話總結：便宜的 ESP32 加上 ESPresense，就能讓 Home Assistant 知道你在哪個房間，最適合拿來補足動作感測器「人不動就失靈」的盲點。
