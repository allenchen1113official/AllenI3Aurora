▶ AI Master〈How to Build an AI Agent with Claude Code (Claude AI Agent Tutorial)〉（2026-06-30・22 分 7 秒）

📌 重點摘要
• 使用 AI 有三個層次：聊天問答、請它產出成品，以及交出完整目標讓它自己規劃執行的代理式工作。
• 真正的代理有三個特徵：照流程走、遇到不確定會停下來問、執行前先釐清需求。
• 在 Claude 桌面版 Code 工作區建專案資料夾，第一步寫 CLAUDE.md：專案背景、關於我、規則（先問三個問題、先給計畫）、資料夾結構。
• 代理系統由三部分組成：工作流程檔（白話 SOP）、Claude（協調者）、工具；最關鍵的是流程檔，不是工具。
• 實作兩個代理：研究報告代理，以及把一份長腳本拆成 3 支短影音腳本加社群貼文包的再利用代理。

📝 康乃爾筆記
🔹 三層次：聊天 → 產出 → 代理：交出目標，而不是一步步指揮
🔹 CLAUDE.md：寫一次、每次自動讀；規則寫進去就不用每次重講
🔹 先看計畫：花 2 分鐘審計畫，省下 10 分鐘收拾殘局
🔹 五個錯誤：跳過 CLAUDE.md、目標模糊、不審計畫、不要求先提問、一次建太多
🔹 擴充路線：單一研究寫作 → 多輪迭代 → 多個工作流串成管線

💡 一句話總結：代理的聰明在說明書而不在工具，先把一個流程跑穩再加下一個。
