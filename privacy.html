生效日期：2026-11-18 ／ 前版：2026-10-23（電子報個資告知）

三句話版本：瀏覽本站不需要註冊，我也不放廣告或分析追蹤。訂閱電子報時我只要你的 Email 和你想收的節奏，不賣名單、信裡沒有追蹤像素、每封信都能一鍵退訂。社群與 YouTube 串接只用來發布我自己的內容，不會蒐集你的帳號資料。

  • 開信與點擊追蹤——信裡沒有追蹤像素，我不知道你有沒有打開、點了哪些連結。
  • 《個人資料保護法》第 6 條所稱之特種個人資料。

目的與利用方式

單一目的：依你選擇的節奏寄送艾倫報報電子報，以及與訂閱直接相關的通知（確認信、歡迎信、設定變更通知、服務異動或停止公告）。對應法定特定目的代號 ○四○ 行銷。以電子檔形式儲存，以電子郵件利用，不會以紙本、電話或簡訊聯絡你；不做名單交換、聯合行銷、廣告投放或轉售。

是否提供 Email 由你自由決定，不提供的影響僅有一項：無法收到電子報。

五、社群平台與 YouTube 串接

本站的 PilotOne 社群發文中控，透過 Meta（Facebook／Instagram）Graph API、Threads API 及 YouTube Data API，把艾倫報報自己製作的內容發布到經營者自己的帳號。

  • 只存取經營者本人授權的自有帳號：發布貼文、圖片與影片，讀取自有頻道與貼文的基本資訊與彙總成效數字（觸及、互動、訂閱數、觀看數等），用於後台統計與首頁顯示。
  • 不蒐集其他使用者的資料：不讀取、不儲存按讚、留言、追蹤者或觀眾的個人帳號資料，也不用於廣告投放。
  • 存取權杖（Token）只存放於加密的機密設定與受保護的資料庫欄位，前端網頁無法讀取，也不會出現在公開程式碼中。
  • 本站對 Google API 所取得資訊之使用與傳輸，遵守 Google API 服務使用者資料政策（含有限使用規定）。使用 YouTube 功能即同時適用 YouTube 服務條款 與 Google 隱私權政策。經營者可隨時於 Google 帳戶安全性設定 撤銷授權。
  • 你在 Facebook、Instagram、Threads、YouTube 上與艾倫報報互動（按讚、留言、追蹤、觀看）時，資料由各平台依其政策處理：Meta 隱私政策、Threads 補充隱私政策、Google 隱私權政策。

六、管理後台

管理後台僅供經營者使用，需以指定的 Google 帳號透過 Firebase Authentication 登入，並由資料庫安全規則限制寫入權限。後台不對外開放註冊。

七、第三方服務與境外傳輸

本站沒有自己的伺服器，運作依賴下列服務。你的資料可能經過它們，且可能存放或處理於中華民國境外：

Google Firebase電子報名單與網站內容的儲存位置（Google Cloud 資料中心）
電子郵件寄送服務實際投遞信件（目前為 Gmail；日後可能改用 Brevo 等寄信服務商），信件內容與收件地址會經過其伺服器
GitHub（Actions／Pages）執行寄信與發文排程、託管網站。排程執行期間會讀取名單，但不會將名單留存在 GitHub 上
Meta、Google（YouTube）發布與讀取自有帳號內容，見第五節

除上述必要技術服務商外，不會將你的個人資料提供給任何第三人；但法律另有規定、或依主管機關、司法機關依法要求者除外。

八、保存期間

  • 訂閱期間：從你完成確認到你退訂為止。
  • 退訂之後：僅保留最少必要欄位（Email、同意與退訂時間），作為「你曾同意、以及你已撤回同意」的軌跡，保留 2 年後刪除。
  • 社群成效數字：僅保留近 30 天之彙總數字，且不含個人資料。
  • 你也可以隨時要求我立即完整刪除，見第九節。

九、你的權利與資料刪除

依《個人資料保護法》第 3 條，你可以：查詢或請求閱覽、請求製給複製本、請求補充或更正、請求停止蒐集處理或利用、請求刪除。

怎麼行使

調整節奏或停止寄信：每封電子報底部都有「管理訂閱」連結，可自行調整或退訂，即時生效。

刪除資料及其他請求：請寄信到 allenchen1113.official@gmail.com，主旨註明「資料刪除請求」或你要行使的權利。我會在收到後 15 日內回覆處理結果。為確認是本人提出，我可能會請你從該訂閱信箱寄出。

透過 Facebook／Instagram／Threads 登入或互動所產生的資料：本站不提供以社群帳號登入，也不保存你的社群帳號資料；如仍有疑慮，可用同一信箱提出刪除請求，或於該平台的「應用程式和網站」設定中移除授權。

行使上述權利不收取任何費用。完整步驟請見資料刪除說明。

十、資料安全

  • 訂閱名單以資料庫安全規則保護：任何人都無法列舉或下載整份名單，也無法用別人的 Email 變更他的訂閱；本站也不提供「輸入 Email 即退訂」，以免他人代你退訂或探測名單。
  • 你的訂閱管理連結帶有一組 32 字元隨機憑證，讓你不必註冊或設密碼——也因此請不要把「管理訂閱」連結轉發給他人。
  • 寄信與社群發文所需的憑證存放於加密的機密設定中，不會出現在公開的程式碼裡。

需要誠實說明的是：沒有任何系統能保證絕對安全。若不幸發生個資事故，我會依法通知你並說明已採取的因應措施。

十一、Cookie 與瀏覽器儲存

本站不使用廣告或分析追蹤 Cookie。本站自己唯一的瀏覽器儲存是：訂閱成功後，在你瀏覽器的 localStorage 存放你的訂閱憑證，讓你下次造訪時能直接進入偏好中心；這筆資料只存在你的裝置上，清除瀏覽器資料即可移除。第三節所列嵌入內容（如 YouTube 播放、Google 日曆）可能依其政策設置自己的 Cookie。

十二、未成年人

本站與電子報內容包含理財與投資觀察，不以未成年人為對象，我也不會在知情下蒐集未滿 13 歲兒童的個人資料。未滿 18 歲者訂閱前，請先取得法定代理人同意。

十三、內容性質聲明

本站、電子報與社群貼文中關於市場、標的或數據的內容，均為資料彙整與個人觀察，不構成任何投資建議或要約，也不保證其正確性或即時性。依此進行之任何決策與後果，由讀者自行承擔。

十四、政策變更與語言

本政策如有修改，會更新本頁最上方的「生效日期」。若變更涉及蒐集目的或利用對象等重大事項，我會另以電子報通知訂閱者，並在必要時重新徵求同意。本政策有繁體中文與英文兩個版本，兩者如有歧異，以繁體中文版為準。

10. Security
