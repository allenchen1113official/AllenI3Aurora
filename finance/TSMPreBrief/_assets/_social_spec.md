# 台股盤前速報｜社群文案與圖卡規格（2026-11-02 版，Allen 核定）

本資料夾（`AllenI3Aurora/finance/TSMPreBrief/_assets/`）為「台股盤前速報」排程的社群資產規格與產生器，
每日執行時**直接沿用**，不要重新設計版面。

## 一、四個固定區塊（順序不可更動）

每張圖卡與每份文案都必須依序涵蓋：

1. **一句話開盤觀點** — 點出今日最該注意的分歧或主軸，一句話。
2. **五市速讀** — 台股、台股期、美股、韓股、日股，皆為「上一交易日收盤」。
   實作上列**九行**（台股期拆為日盤／夜盤，美股拆為四個指數 — 2026-11-02 Allen 核定）：

   | 行 | 內容 | 補充欄 |
   |---|---|---|
   | 台股 加權 | 收盤、漲跌幅 | 櫃買指數收盤與漲跌幅 |
   | 台股期 N月 | 近月台指期日盤收盤、漲跌幅 | 漲跌點數、對現貨正／逆價差 |
   | 台股期 夜盤 | 夜盤收盤、漲跌幅 | 漲跌點數、關鍵價位 |
   | 美股 道瓊 DJI | 收盤、漲跌幅 | 漲跌點數 |
   | 美股 S&P 500 | 收盤、漲跌幅 | 漲跌點數 |
   | 美股 那斯達克 | 收盤、漲跌幅 | 漲跌點數、單日跌幅排名等 |
   | 美股 費半 SOX | 收盤、漲跌幅 | 漲跌點數、台積電 ADR 漲跌幅 |
   | 韓股 KOSPI | 收盤、漲跌幅 | 代表個股（SK海力士、三星等） |
   | 日股 日經 225 | 收盤、漲跌幅 | 漲跌點數、領跌／領漲族群 |

   美股四個指數為固定組合，不可省略或替換；四個都要列收盤點數與漲跌幅，漲跌點數放補充欄。

3. **績優選股** — 即主報告「均線多頭 ＋ 大戶增持 ＋ 量增」三條件掃描結果。
   - 有標的：列出入選個股（代號、名稱、收盤、漲跌幅、量能倍數、一句話）。
   - **0 檔時（Allen 核定做法）**：大字誠實寫「今日無符合三條件之標的 · 上市 X 檔、上櫃 Y 檔」，
     下方列出 a ∩ c 成立但卡在條件 b 的「最接近者」與卡關原因，**不放寬條件、不改用其他口徑湊數**。
   - 一律附一行掃描覆蓋率（實際掃描檔數／150，百分比），說明這是已覆蓋範圍內的結論。
4. **今日財經行事曆** — 四個標籤：台灣／美國／財報／國際。只寫「項目與市場預期」，不引用現值。

## 二、圖卡（三張，各平台一張）

| 平台 | 尺寸 | 檔名 |
|---|---|---|
| Facebook | 1200 × 630（橫式，兩欄） | `TSMPreBrief_FB_YYYY-MM-DD.png` |
| Instagram | 1080 × 1350（4:5 直式） | `TSMPreBrief_IG_YYYY-MM-DD.png` |
| Threads | 1080 × 1080（方形） | `TSMPreBrief_Threads_YYYY-MM-DD.png` |

**產生方式：不要自己重寫版面。**
1. 把本資料夾的 `make_social_cards.py` 與 `card_data.json` 複製到雲端工作區。
2. 依當日資料改寫 `card_data.json`（欄位見下）。
3. 執行 `python3 make_social_cards.py <輸出目錄>`。
   腳本會先量測內容自然高度，再以 CSS `zoom` 等比縮放塞進固定尺寸，**不會溢出、不會裁切**；
   終端會印出 `natural / zoom / final` 與 `OK`，若出現 `STILL OVERFLOWING` 才需處理。
4. 用 Read 檢視三張圖，確認：徽章 `AI³A` 單行未溢出、中文無方框亂碼、紅漲綠跌正確、頁尾兩行可見。

### card_data.json 欄位
- `date_iso` `"YYYY-MM-DD"`、`date_zh` `"YYYY 年 M 月 D 日（週X）"`
- `basis` 資料基準列（須寫明上一交易日與中間休市日）
- `view` 一句話開盤觀點
- `markets` 六列，每列 `[名稱, 收盤, 漲跌幅, 補充]`；漲跌幅以 `−`／`＋` 開頭，腳本依符號自動上色
- `picks_headline` 績優選股的大字結論列
- `picks` 每檔 `[代號, 名稱, 收盤, 漲跌幅, 量能倍數, 備註]`
- `picks_note` 覆蓋率與卡關說明
- `calendar` 四列，每列 `[標籤, 內容]`

### 品牌規範（已內建於腳本，勿更動）
MINT `#92E0BE`、BLUE `#4F8AD5`、INK `#12332B`、SAGE `#2F6152`、PAPER `#DEE7E2`；
漲跌沿用台灣慣例 紅漲 `#C9342F`／綠跌 `#0F7D62`，品牌色只用於結構性裝飾。
徽章為 mint→blue 漸層圓角方塊，內含單行 `AI³A`，右側同列並排「艾倫極光報報」＋細分隔線＋`Allen I³ Aurora Brief`。
頁尾固定兩行：`Allen I³ Aurora Brief · 艾倫極光報報` 與 `Allen Chen · Est. 2026`。

## 三、文案（四份）

| 檔名 | 用途 | 長度與語氣 |
|---|---|---|
| `SocialPost_FB_YYYY-MM-DD.txt` | Facebook | 最完整；四區塊以 `■` 分段，可含籌碼面補充段；hashtag 一行 |
| `SocialPost_IG_YYYY-MM-DD.txt` | Instagram | 中等；四區塊以 `【】` 分段，行距鬆、條列為主；≤2,200 字元、hashtag ≤30 |
| `SocialPost_Threads_YYYY-MM-DD.txt` | Threads | **≤500 字元（發文前用 Python `len()` 驗證）**；一則完成不串文，主題標籤 ≤3 |
| `SocialPost_TSMPreBrief_YYYY-MM-DD.txt` | 前台「今日關注動態」卡片來源 | 見下方格式契約 |

### SocialPost_TSMPreBrief 格式契約（`scripts/update-focus.mjs` 會解析，不可破壞）
- 第 1 行：品牌抬頭，含「艾倫極光報報」與「台股盤前速報」字樣（會被自動略過）
- 第 2 段第 1 句：約 10～18 字、以「，」或「。」收尾的重點句
- 之後 8～10 行完整句子，依四區塊順序鋪陳（觀點 → 台股 → 台股期 → 美股 → 韓日股 → 籌碼 → 選股 → 覆蓋率 → 行事曆）
- 最後一行：hashtag

### 共同用詞規則
- 全篇禁用「昨日／昨天／昨收／隔夜」；台股寫「上一交易日（M/D 週X）」，美股寫「上一美股交易日（美東 M/D）」。
- 名稱一律「台股盤前速報」，不可寫成盤前摘要／盤前解析／盤前脈動。
- 數字只採收盤值，不用盤中快照；不確定就寫「資料未取得」。
- 文末固定「本內容為資料彙整，非投資建議」。

## 四、新增的資料需求（相對於舊版）
舊版速報未取韓股與日股，新版必須補齊：
- **韓股 KOSPI**：搜尋「KOSPI 收盤 M/D」「日韓股市收盤」等，核對是否為目標交易日；
  不同來源常有小數差異（實測 5,728.04 vs 5,730.74），擇一並揭露差異。
- **日股 日經 225**：同上。
- **台指期日盤**：中央社「N月台股期指跌／漲 X 點」稿有收盤、漲跌點數與正逆價差。
- **台指期夜盤**：工商時報「期交所夜盤行情」或當日美股彙整稿。
