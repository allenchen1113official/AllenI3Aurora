### 台積電 ADR 對 2330 的折溢價（算式）

```
1 單位 ADR = 5 股台積電普通股
折合台股價 = 472.78 ÷ 5 × 31.830 = 94.556 × 31.830 ≒ NT$3,009.7
溢價率   = (3,009.7 − 2,500) ÷ 2,500 = +20.39%
→ ADR 對台北交易溢價約 20.4%
```

匯率採新台幣 10/02 台北銀行間收盤 31.830 元；若以 10/01 收盤 31.84 元計算，折合台股價約 3,010.6 元、溢價約 +20.4%，結論不變。

### 卡在哪一關：受阻原因與影響範圍

1. **卡在條件 a 與 c（上游資料欄位）。** MA5／MA20／MA60／MA240 與 20 日均量，在本環境可抓取的所有頁面（玩股網 technical-chart、HiStock、Yahoo 股市技術分析、MONEY LINK、CMoney、poorstock）皆由前端 JavaScript 繪製，純文字擷取取不到數值。缺 20 日均量 → c 無法判定；缺四條均線（尤其 MA240 年線）→ a 無法判定。
2. **唯一有完整均線數值的來源已證實不可信。** 鉅亨 `Technical.aspx` 同頁提供 MA5／20／60／240 與 20 日均量，但實測有兩項致命缺陷：① 資料落後 1～7 個交易日且頁面日期標籤錯亂；② **忽略 code 參數並回傳錯誤標的**——請求 3533 嘉澤回傳鴻海 2317、請求 2888 新光金回傳台達電 2308、請求 4147 中裕回傳台積電 2330、請求 2603 長榮回傳台達電。Goodinfo 的 `StockDetail.asp` 有同樣的標的錯置問題（7 次請求有 5 次回錯標的）。照抄這些數字等同編造，故全數棄用。
3. **抓取權限（provenance）限制收緊為「逐個網址」。** 自行拼湊的網址（即使同網域、僅更換股號）一律被擋；每檔必須先以搜尋取得逐字相符的完整網址再抓取，單檔至少 2～3 次呼叫，150 檔的呼叫成本遠超可用額度。
4. **條件 b 反而是可用的（唯一完整可取得者）。** 玩股網 `major-investors/concentration` 可直接讀出「400 張以上」大戶持股比率的逐週序列。抽測：晶技(3042) 56.64% → 59.08%（**+2.44 pp**）、群聯(8299) 39.55% → 39.21%（−0.34 pp）、智邦(2345) 70.25% → 70.31%（+0.06 pp）；集保週別為 2026/09/24 與其前一期，對 10/02 交易已落後約 4～6 個交易日。惟依規則須 a ∩ c 先成立才採計 b，故上述數字**不**構成選股結果，僅作為方法可行性紀錄。

**影響範圍量化**：150 檔中 **0 檔（0%）** 完成三條件驗證；約 17 檔（約 11%）僅取得 10/02 的收盤與成交量；**100% 的標的無法驗證條件 a 與 c**。條件 b 的資料管道可用，但因前置條件未成立而未啟用。

## 6. 今日盤前觀察重點與行事曆

### 觀察重點（僅資料整理與觀察）

1. **台美溫差與權值補漲能否接棒。** 台積電 ADR 折合台股約 3,010 元、對台北交易溢價約 20.4%，而 2330 上一交易日收 2,500 元（−10 元）、成交量僅約 1.4 萬張。距收盤前高 48,601 點僅約 125 點，權值股今日能否放量補漲是挑戰前高的關鍵變數。
2. **夜盤已先行，留意開高後的追價量能。** 台指期 10/02 夜盤收 49,346 點（+677 點），高於現貨約 870 點。上一交易日集中市場成交值 8,982 億元，若開高後量能未同步放大，開高走低的機率需納入考量。
3. **期現貨方向不一致。** 外資現貨連三買，但台指期未平倉淨空單增至 80,304 口、重回 8 萬口以上高檔水位；期現貨背離下的盤中震盪幅度通常放大。
4. **急漲題材的接力順序。** ABF 載板（臻鼎-KY 漲停、欣興 +7.41%）、被動元件（華新科漲停、國巨 +3.99%）、矽光子／CPO（穩懋漲停）已出現多檔漲停，今日需觀察是續強還是獲利了結；原物料線（油電燃氣 +5.51%、化學 +2.83%、塑膠 +2.75%）是否延續報價題材。
5. **籌碼偏多但未極端。** 融資餘額增至 6,351.04 億元（+52.37 億）、券資比 2.47%；搭配櫃買 +1.94% 的中小型股熱度，短線過熱後的回檔風險值得留意。
