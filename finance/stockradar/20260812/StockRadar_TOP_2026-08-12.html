資料來源與方法論說明

  • TOP10排行來源：Google Drive／StockRadar／StockList 試算表 TOP 工作表（gid=0）。
  • 股價／漲跌幅／KD：台灣證券交易所（TWSE）STOCK_DAY API 或證券櫃檯買賣中心（TPEx）tradingStock API 之每日開高低收資料計算。KD參數：RSV週期N=9日，K值平滑=前值×2/3+RSV×1/3，D值平滑=前值×2/3+K×1/3，初始K=D=50。「黃金交叉」定義為前一交易日K<D、當日K>D。
  • 大戶／散戶連買週數：Goodinfo!台灣股市資訊網「股權分散表（週）」。大戶比例＝(＞800~≤1,000張)＋(＞1,000張)兩級持股佔比加總；散戶比例＝(≤10張)＋(＞10~≤50張)兩級持股佔比加總；連買週數＝比例連續較前一週增加之週數，本週較上週減少則歸零。
  • 均線多頭排列：Goodinfo!「均線落點」資料。定義為月線＞季線＞半年線＞年線，且四條均線箭頭皆為向上（↗）；若無半年線或年線資料則標示「資料不足」並視為不成立。
  • 單季營益率／營收年增／EPS年增近4季達標：Goodinfo!「單季經營績效」資料。取最近4個已公告季度，分別判斷單季營益率是否>10%、單季營收較去年同季成長是否>20%、單季EPS較去年同季成長是否>10%；各項達標≥3季則視為整體達標（true）。若去年同期基期金額過小（如EPS<0.1元），成長率數值參考性較低，已於對應儲存格加註提醒。
  • 客觀短評：依當日漲跌幅、KD數值與均線排列狀態自動生成之中性技術面描述，僅供參考，非投資建議，亦非使用者原創之「艾倫小評」內容。
